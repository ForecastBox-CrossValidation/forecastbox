# Forecast Evaluation Examples

Examples demonstrating statistical forecast evaluation using forecastbox.

## Notebooks

| # | Notebook | Topic |
|---|----------|-------|
| 1 | `01_diebold_mariano.ipynb` | Diebold-Mariano test for equal predictive ability |
| 2 | `02_model_confidence_set.ipynb` | Model Confidence Set (Hansen, Lunde, Nason) |
| 3 | `03_giacomini_white_encompassing.ipynb` | Giacomini-White test and forecast encompassing |

## Datasets

- `inflation_forecasts.csv` - Actual inflation + 5 model forecasts (shared with combination)
- `m4_sample.csv` - M4-like series with model forecasts (shared with combination)
