# Nowcasting Examples

Examples demonstrating nowcasting methods using forecastbox.

## Notebooks

| # | Notebook | Topic |
|---|----------|-------|
| 1 | `01_dfm_nowcaster.ipynb` | Dynamic Factor Model for nowcasting |
| 2 | `02_bridge_equations.ipynb` | Bridge equations approach |
| 3 | `03_midas.ipynb` | MIDAS (Mixed Data Sampling) regression |

## Datasets

- `gdp_vintages.csv` - GDP data vintages with revision history (40 quarters, 5 vintages)
- `mixed_freq.csv` - Monthly indicators + quarterly GDP (120 months)
- `macro_brazil.csv` - Monthly Brazilian macro data (shared with basic_forecasting)
