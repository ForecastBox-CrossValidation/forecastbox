# Scenario Analysis Examples

Examples demonstrating conditional forecasting and scenario analysis using forecastbox.

## Notebooks

| # | Notebook | Topic |
|---|----------|-------|
| 1 | `01_conditional_forecast.ipynb` | Conditional forecasting (Waggoner-Zha) |
| 2 | `02_scenarios_fan_charts.ipynb` | Scenario analysis with fan charts |
| 3 | `03_stress_test.ipynb` | Stress testing forecasts |

## Datasets

- `us_macro_quarterly.csv` - Quarterly US macro data (1990-2024): GDP, inflation, fed funds, unemployment
- `macro_brazil.csv` - Monthly Brazilian macro data (shared with basic_forecasting)
