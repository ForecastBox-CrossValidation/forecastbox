# Forecast Combination Examples

Examples demonstrating forecast combination methods using forecastbox.

## Notebooks

| # | Notebook | Topic |
|---|----------|-------|
| 1 | `01_simple_weighted.ipynb` | Simple average and weighted combinations |
| 2 | `02_ols_granger_ramanathan.ipynb` | OLS combination (Granger-Ramanathan) |
| 3 | `03_stacking_bma.ipynb` | Stacking and Bayesian Model Averaging |
| 4 | `04_time_varying.ipynb` | Time-varying combination weights |

## Datasets

- `inflation_forecasts.csv` - Actual inflation + 5 model forecasts (120 months)
- `m4_sample.csv` - M4-like series with 3 model forecasts (6 series)
