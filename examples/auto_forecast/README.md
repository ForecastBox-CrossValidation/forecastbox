# Auto-Forecast Examples

Examples demonstrating automatic model selection using forecastbox.

## Notebooks

| # | Notebook | Topic |
|---|----------|-------|
| 1 | `01_auto_arima.ipynb` | AutoARIMA model selection |
| 2 | `02_auto_ets.ipynb` | AutoETS (exponential smoothing) |
| 3 | `03_auto_select_var.ipynb` | AutoSelect and AutoVAR |

## Datasets

- `m3_sample.csv` - Sample of M3-like time series (10 series, monthly/quarterly)
- `airline.csv` - Classic airline passengers dataset (144 monthly observations)
